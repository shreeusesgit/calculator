# 🧮 Modern Calculator

A sleek and responsive **web-based calculator** built using **HTML, CSS, and JavaScript**.
This project demonstrates clean UI design, interactive functionality, and core front-end development skills.
## 🚀 Live Demo

🔗 https://calculator-psi-gray-36.vercel.app
## 📌 Features

* Basic arithmetic operations (+, −, ×, ÷, %)
* Clean and modern UI design
* Responsive layout (works on different screen sizes)
* Smooth button interactions
* Error handling for invalid inputs
## 🛠️ Tech Stack

* **HTML5** – Structure
* **CSS3** – Styling & layout (Grid, Flexbox)
* **JavaScript (Vanilla)** – Logic & functionality

📦 Deployment

This project is deployed on Vercel for fast and reliable hosting.
